# Security and data handling

This project is a portfolio demonstration. Do not upload a customer RFP, CRM export,
API key, or any personal/sensitive data unless you have explicit authorization and
appropriate data-processing approval.

- Keep secrets in environment variables or Streamlit secrets, never in Git.
- Use anonymized, minimal data for demonstrations.
- Review generated claims, product scope, commercial terms, and citations before
  sharing a proposal externally.
- Report security concerns privately to the repository owner rather than publishing
  sensitive details in an issue.
